# Sources

Drop your raw brand material here: guidelines, past posts and emails, decks, about pages, product sheets. PDFs, images, text and markdown work best. Save Word files, Google Docs and slides as PDF first.

Your AI reads these to draft the files in `knowledge/` and `brand/`. It never edits this folder. When a brand file and a source disagree, the brand file wins, because it's the version you've confirmed.
